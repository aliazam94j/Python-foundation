# Python Foundation

## Who I am

I am a first-year IoT student. Most of my coursework is in C and embedded
systems — that work lives in my other repositories, including
[C-foundation](https://github.com/aliazam94j/C-foundation).

## Why this repo exists

This one's just for fun, on the side, not tied to an assignment. Python
comes up constantly around embedded work — scripting, quick tools, and it's
also what I'm using for the Flask backend on my
[daily checklist device project](https://github.com/aliazam94j/LIA-Projects/tree/main/daily-checklist-device).
Rather than only picking it up piecemeal when a project needs it, I wanted a
place to deliberately practice the fundamentals — the same instinct behind
`C-foundation`, just applied to a second language.

## What is in this repo

| File | What it covers |
|---|---|
| `calculator.py` | Basic operator branching — `+ - * /` on two user-entered numbers |
| `weight_converter.py` | Unit conversion (kg ↔ lb) based on user choice |
| `bill_splitter.py` | Splitting a total across a number of people, with a guard against splitting by zero or fewer |

Small scripts on purpose — each one isolates a handful of fundamentals
(`input`, type conversion, `if`/`elif` chains, f-strings) rather than trying
to build something bigger before the basics are solid.

## Where I am heading

Looking for a LIA placement in embedded systems or IoT — this repo isn't
part of that path directly, but a second language rounds out what I can
bring to a team beyond just C.
